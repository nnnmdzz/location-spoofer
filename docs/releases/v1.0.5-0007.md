# v1.0.5-0007

发布日期：2026-08-12

这是 `0006` 之后的语言声明修复版本，重点解决应用主体为中文、但依赖组件和系统本地化内容被 iOS 按英文环境解析的问题。

## 修复

- 将 App 的默认开发语言明确声明为 `zh-Hans`，使系统按照应用真实界面语言解析本地化资源。
- 在 `Info.plist` 中明确声明支持 `zh-Hans` 和 `en`，避免依赖组件因宿主 App 语言声明缺失而错误回退到英文。
- 在 `project.yml` 中固定 `developmentLanguage: zh-Hans`，避免后续 XcodeGen 重新生成工程时把开发语言恢复成默认英文。
- 修复“私人 IPA 签名”等依赖 `PrivateSigner` 本地化界面在中文 App 中显示英文的问题；同类系统提供字符串也会随宿主语言声明正确解析。

## 测试与回归保护

- 新增语言声明契约测试，固定 `CFBundleDevelopmentRegion`、`CFBundleLocalizations` 和 XcodeGen `developmentLanguage` 三处配置。
- 保持 `0006` 的 Private Signer SDK 接入、Keychain 存储身份和自定义更新流程不变，本版本不修改签名协议或服务端 API。

## 版本

- 对外发行版本：1.0.5-0007
