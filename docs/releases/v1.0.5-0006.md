# v1.0.5-0006

这是私人签名通道从 Location Spoofer 专用协议迁移到通用 IPA 签名任务的过渡版本。

## 新增

- “增强功能 → 私人 IPA 签名”现在可以提交任意可重签名 IPA 的 HTTPS 下载链接，或直接选择本地 IPA 文件上传。
- 本地文件按 8 MiB 分片上传，单个来源当前上限为 100 MB。
- 默认使用 Split 签名，也可显式选择 Standard；高级选项支持目标 Bundle ID、Profile ID、Keychain 访问组和兼容性策略。
- 任务页显示最近 30 天历史，在 App 前台时每 5 秒刷新进行中的任务，并支持取消、重试、安装和导出。
- 完成后的签名 IPA 保留 7 天；安装和导出链接每次生成后有效 15 分钟，可随时重新生成。

## 配置迁移

- Worker 地址和 Token 会从旧 Keychain 访问组迁移到稳定访问组。
- 本版本的私人签名请求默认同时保留稳定访问组和旧显式 profile 访问组，避免 OTA 覆盖安装后看起来像“配置被清空”。
- 配置界面中的 Token 名称更新为 Signing Request Token；迁移阶段可继续使用设备里已有的同一 Token 值。

## 兼容与安全

- 仅支持 iOS/iPadOS 的可重签名 IPA，不提供 FairPlay 解密。
- 默认移除 profile 不支持的嵌套包和权限并写入报告；也可选择必须全部保留，遇到不兼容即失败。
- 旧的 `v1` 私人更新入口仍保留，用于从 `0005` 覆盖安装并验证本版本；真机确认迁移成功前不会删除旧通道。
