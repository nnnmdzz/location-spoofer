# v1.0.5-0001

发布日期：2026-08-10

基于上游版本：v1.0.5

## 上游同步

- 同步上游 v1.0.3 至 v1.0.5 的变更与修复。
- 保留上游新版引导、远程更新检查与配置能力。
- 保留上游第三方代理模块的新脚本体系、双 WLOC 域名支持与模块版本/能力检测。
- 保留上游运动状态模拟、证书/代理流程改进及相关文档与测试更新。

## Fork 功能

- 保留 Core Location 软刷新能力，用于请求更新鲜的定位样本。
- 保留定位生效诊断面板，区分已生效、缓存待刷新、疑似 GPS/GNSS 占优等状态。
- 自动生效检测最多 3 次：首次立即执行，之后约每 10 秒一次；已生效时提前结束，手动重新检测仅执行一次。
- 保留 WLOC 全局精度配置基础能力，支持 1–1000m 范围及 25m、10m、5m、1m 预设。
- APP 本机代理模式与第三方代理模式统一使用 fork 的 WLOC 精度配置，并接入定位生效监控。
- 保留定位服务私有设置 URL 多级回退；定位服务快捷入口失败时提示手动路径，不回退到本 App 设置页。

## 版本信息

- 对外发行版本：1.0.5-0001
- iOS `CFBundleShortVersionString`：1.0.5
- iOS `CFBundleVersion`：7
- `ForkReleaseVersion`：1.0.5-0001

## 安装说明

- Release 附件为未签名 IPA，安装前需要自行签名。
- 本版本以已手动同步到 fork `main` 的上游 v1.0.5 为基线，并重新叠加 fork 自定义定位功能。
- WLOC 精度更小不代表一定能够压过强 GNSS/GPS；实际效果仍受 iOS Core Location 融合策略影响。
- 定位服务私有设置 URL 的可用性取决于 iOS 版本；全部失败时请按 App 提示手动进入“设置 → 隐私与安全性 → 定位服务”。
