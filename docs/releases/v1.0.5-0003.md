# v1.0.5-0003

发布日期：2026-08-11

基于上游版本：v1.0.5

## 本次更新

- iOS 16+ Shortcuts 新增“获取收藏位置”动作，可返回收藏实体列表，并向后续快捷指令步骤暴露名称、UUID 和 WGS-84 经纬度；可组合“获取收藏位置 → 从列表中选取 → 设置虚拟定位”。
- 首页搜索栏旁新增独立“增强功能”入口；设置页不再重复放置“增强功能”，但原有“检查更新”入口继续保留。
- 增强功能新增“我的快捷指令”，可登记并直接运行用户在系统 Shortcuts App 中创建的快捷指令，支持无输入、固定文本、当前剪贴板，以及 x-callback 成功/取消/错误回传。
- 新增 iOS 桌面长按 App 动态快捷入口：最近使用的两个收藏位置、关闭虚拟定位、增强功能。最近位置只在虚拟定位真正设置成功后更新。
- App 内、App Intent 和桌面长按收藏统一复用现有定位业务服务，不增加第二套坐标转换或 WLOC 写入逻辑。
- 更新页新增可选私人 signed OTA 通道：Worker 地址和 Personal Update Token 均由用户自行配置并保存在本机 Keychain；源码和公开发行包不内置私人服务地址或凭据。
- 私人 OTA 未配置、鉴权失败或 signed 版本尚未准备好时，公开 unsigned GitHub Release 仍可独立检查、复制和下载，不形成单点故障。
- 为上述功能增加 shell contract，并通过 Core Go、WLOC JavaScript 和 Device Release 构建验证。

## 私人签名更新说明

- 本公开 Release 仍只附带未签名 IPA，不包含开发证书、私钥、provisioning profile、Worker 地址或 Personal Update Token。
- “直接安装已签名版本”只有在用户自行部署并配置私人 signer + Worker + 私有存储后才会可用；默认安装状态下仅使用公开 unsigned 更新通道。
- 私人更新配置使用设备本地 Keychain 的 ThisDeviceOnly 可访问级别保存，清除私人配置后不会影响公开更新。

## 安装说明

- Release 附件为未签名 IPA，安装前仍需要自行签名；如果尚未部署私人 OTA，可继续使用现有手机端签名工具安装。
- App Shortcuts / App Intents 功能要求 iOS 16 或更高版本；主 App 最低部署版本仍为 iOS 15。
- 桌面长按快捷动作在未完成当前运行模式初始化时会先进入 App 完成必要配置，不会虚报设置成功。
- 用户自建系统快捷指令需要先在“增强功能 → 我的快捷指令”中登记与 Shortcuts App 完全一致的名称。
