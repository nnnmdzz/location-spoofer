# v1.0.5-0004

发布日期：2026-08-11

基于上游版本：v1.0.5

## 本次更新

- 私人签名 OTA 请求现在会携带当前已安装 App 的 Bundle ID，使 Worker 能选择与设备上现有客户端身份一致的 provisioning profile，避免 Split-ID 签名时身份漂移。
- App 会校验 Worker 返回的 Bundle ID；如果返回结果与当前安装包不一致，会明确提示错误，不会继续展示错误身份的安装入口。
- 私人签名状态页会显示当前请求的 Bundle ID，便于核对 Worker、签名队列和设备安装身份。
- 私人更新配置继续保存在本机 Keychain；公开发行包仍不包含 Worker 地址、Personal Update Token、证书、私钥或 provisioning profile。

## 版本信息

- 对外发行版本：1.0.5-0004
- iOS `CFBundleShortVersionString`：1.0.5
- iOS `CFBundleVersion`：10
- `ForkReleaseVersion`：1.0.5-0004

## 安装说明

- Release 附件是未签名 IPA，需要先用与你当前设备和 App 身份匹配的证书及 provisioning profile 签名。
- 首次安装本版本后，在“设置 → 检查更新”中配置私人 Worker 地址和 Personal Update Token；以后检查新版本时会自动提交当前 Bundle ID。
- 如果要覆盖安装旧版本，签名后的新 IPA 必须保持与手机现有 App 相同的 Bundle ID；否则 iOS 会把它视为另一个 App。
