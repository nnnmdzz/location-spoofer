# v1.0.2-0001

发布日期：2026-08-08

基于上游版本：v1.0.2

## 主要变更

- 增加 Core Location 软刷新能力，用于请求更新鲜的定位样本。
- 增加定位生效诊断，区分已生效、缓存待刷新、疑似 GPS/GNSS 占优等状态。
- 增加定位诊断状态 UI 与重新检测入口。
- 将本地 WLOC 模式接入定位生效监控。
- 将第三方代理模式接入定位生效监控。
- 增加定位服务设置快捷入口及回退路径。

## 版本规则

- 对外发行版本采用“上游版本号-四位序号”。
- 当前发行版本：1.0.2-0001。
- 同一上游基线内序号递增；跟进新的上游版本后从 0001 重新开始。

## 安装说明

- Release 附件为未签名 IPA，安装前需要自行签名。
- iOS 包内 CFBundleShortVersionString 保持为上游版本 1.0.2。
- ForkReleaseVersion 记录完整发行标识 1.0.2-0001。
