# v1.0.5-0005

发布日期：2026-08-11

基于上游版本：v1.0.5

## 本次更新

- 延续 `v1.0.5-0004` 的 Bundle ID 感知私人 OTA 协议，用于验证已安装新客户端发现更高版本、向 Worker 提交签名请求并取得 OTA 安装入口的完整流程。
- 私人签名请求携带当前已安装 App 的 Bundle ID，并校验 Worker 返回身份，避免 Split-ID 更新时发生应用身份漂移。
- 发布构建会自动选择 GitHub runner 当前可用的 iPhone Simulator，并运行完整 iOS 单元测试后才创建 Release。
- 公开发行包仍不包含 Worker 地址、Personal Update Token、证书、私钥或 provisioning profile。

## 版本信息

- 对外发行版本：1.0.5-0005
- iOS `CFBundleShortVersionString`：1.0.5
- iOS `CFBundleVersion`：11
- `ForkReleaseVersion`：1.0.5-0005

## 更新验证

- 在已安装 `v1.0.5-0004` 的手机上打开“设置 → 检查更新”，客户端应发现本版本并向已配置的私人 Worker 提交 `tag + bundle_id` 请求。
- Worker 首次返回“准备中”后，可等待定时 signer，或手动运行 Private IPA Signer；签名完成后再次检查即可显示 OTA 安装入口。
