# v1.0.5-0010

发布日期：2026-08-12

`v1.0.5-0010` 修复 `0009` 私人签名配置中“Worker 地址正确但客户端 Token 被拒绝”的问题，并将私人签名能力统一回 Private Signer 的单一 v2 契约。

## 私人签名

- App 与 SDK 只使用 `/v2/*`；不再维护第二套客户端协议。
- 继续使用现有 `SIGNING_REQUEST_TOKEN`，已保存在 Keychain 的 Worker URL/Token 不需要改成另一种 Token 类型。
- App 仍只编译稳定项目 ID `location-spoofer`，不硬编码 Profile ID。
- SDK 从 Worker 动态获取项目 ProjectVersion 与真实 Profile Set，并使用 `project_id + version_id + profile_id` 创建签名 Job。
- 项目签名的 unsigned IPA source URL、digest 与 expected version 仍由 Worker 管理，客户端不能覆盖。
- 删除 `personal-main` 的客户端约定；Profile 选择只使用 Worker 返回的真实 Profile Set ID。

## Worker 配套

- Worker `/health` 返回单一 `contract: v2`，并显示 Worker 实现版本。
- `/admin` 显示当前 Worker 版本；`/admin/v2` 提供项目版本、GitHub 同步和 allowed/default Profile 配置。
- 项目/Profile discovery 与现有 URL/upload 签名共用一个 v2 Token 和同一签名队列。
