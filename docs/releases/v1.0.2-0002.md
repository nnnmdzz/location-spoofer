# v1.0.2-0002

发布日期：2026-08-08

基于上游版本：v1.0.2

## 主要变更

- 增加 WLOC 定位精度全局配置，支持 25m、10m、5m、1m 预设。
- 支持 1–1000m 自定义整数精度，并持久化保存。
- APP 本机代理模式与第三方代理模式统一使用当前 WLOC 精度配置。
- 定位生效监控移动到运行日志/环境检测页面，不再放在“无法生效”故障说明中。
- 自动定位生效检测调整为最多 3 次：首次立即检测，之后约 10 秒间隔；已生效时提前结束。
- 取消 App 回到前台后自动重复检测；“重新检测”按钮改为单次立即检测。
- 定位服务设置快捷入口增加多条定位/隐私私有 URL 回退链。
- 定位服务快捷入口全部失败时只提示手动路径，不再回退到本 App 设置页。

## 版本信息

- 对外发行版本：1.0.2-0002
- iOS `CFBundleShortVersionString`：1.0.2
- iOS `CFBundleVersion`：5
- `ForkReleaseVersion`：1.0.2-0002

## 安装说明

- Release 附件为未签名 IPA，安装前需要自行签名。
- WLOC 精度数值表示提供给 WLOC 定位响应的 accuracy 配置；更小的值不保证一定能够压过强 GNSS/GPS 定位。
- 定位服务私有设置 URL 的可用性取决于 iOS 版本；全部失败时请按 App 提示手动进入“设置 → 隐私与安全性 → 定位服务”。
