# v1.0.5-0009

发布日期：2026-08-12

> 此版本的私人签名协议迁移方案已经被 `v1.0.5-0010` 取代。新的安装和私人更新请使用 `0010`；`0009` 仅保留为历史发行记录。

`v1.0.5-0009` 完成了私人签名架构中最重要的客户端解耦：App 不再硬编码 Profile ID，也不再把 unsigned IPA URL 作为私人自更新签名源传给 Worker。

## 已完成的修复

- App 只保留稳定项目身份 `location-spoofer`。
- 私人自更新使用 Worker 管理的 ProjectVersion 和真实 Profile Set ID。
- 删除客户端 `personal-main` 约定与默认值。
- “复制公开 unsigned IPA 地址”与私人签名链路彻底分离。
- Keychain service 和 Stable Configuration Group 保持不变，避免已安装 App 丢失本机配置。

## 后续修正

该版本引入的临时协议拆分与现有客户端 Token 配置不一致，因此已经由 `v1.0.5-0010` 修正。`0010` 将上述项目版本/Profile discovery 能力全部统一回 Private Signer 的单一 v2 契约，并继续使用现有 Signing Request Token。
