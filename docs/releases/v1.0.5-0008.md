# v1.0.5-0008

发布日期：2026-08-12

`v1.0.5-0008` 是 `0006` 之后第一个完整可安装的发行版本。此前创建的 `v1.0.5-0007` GitHub Release 未成功产出 IPA 附件，因此本版本直接取代该不完整发行，不重写已经公开的 `0007` tag。

## 修复

- 将 App 的默认开发语言明确声明为 `zh-Hans`，修复中文 App 内依赖组件及系统本地化内容错误显示英文的问题。
- 明确声明 `zh-Hans` 和 `en` 本地化能力，并通过 XcodeGen 配置固定开发语言，避免工程重新生成后回退到英文。

## 发布流程

- Release CI 不再要求每个版本都必须手工维护 `docs/releases/<version>.md`。
- 如果存在人工编写的版本归档，发布时优先采用；如果缺失，则根据上一个 Git tag 到当前发行提交的 Git 历史自动生成 Release 说明。
- 自动生成逻辑同时支持 release 分支发布和 tag 已经指向当前提交后的发布场景，避免出现空的 `VERSION..VERSION` 提交区间。

## 兼容性

- 保持 `PrivateSigner` SDK 0.1.1、现有 Keychain 存储身份、自更新配置及签名服务协议不变。
- 本版本不修改公开 Bundle ID、App Group 或现有签名 entitlements。

## 版本

- 对外发行版本：1.0.5-0008
- iOS `CFBundleShortVersionString`：1.0.5
- iOS `CFBundleVersion`：13
- `ForkReleaseVersion`：1.0.5-0008
