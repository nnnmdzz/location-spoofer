# v1.0.5-0002

发布日期：2026-08-11

基于上游版本：v1.0.5

## 本次更新

- 将 fork 更新检查改为仅在设置页手动触发，不再在 App 启动时自动检查。
- 更新源改为 `nnnmdzz/location-spoofer` 正式 Releases，按完整 `X.Y.Z-NNNN` 版本比较。
- 更新结果直接使用 GitHub API 返回的真实 IPA 下载地址；Release 缺失对应 IPA 时明确报错。
- 新增统一“增强功能”入口，集中 WLOC 精度、定位生效诊断和系统设置快捷入口。
- WLOC 精度配置重新可见，APP 模式和第三方代理模式继续统一使用同一精度值。
- 新增 iOS 16+ App Intents / Shortcuts：
  - 设置虚拟定位到收藏位置
  - 关闭虚拟定位
  - 查看虚拟定位状态
- 快捷指令复用现有 `LocationActionCoordinator` / `ThirdPartyProxyManager`，不新增第二套坐标转换逻辑。
- Bug、功能建议和第三方配置提交入口统一写入 fork 仓库，upstream 仅保留只读归属链接。

## 安装说明

- Release 附件为未签名 IPA，安装前需要自行签名。
- iOS Shortcuts 功能要求 iOS 16 或更高版本；主 App 最低部署版本仍为 iOS 15。
- WLOC 精度更小不代表一定能够压过强 GNSS/GPS；定位生效诊断仍属于启发式判断。
- 定位服务私有 prefs/App-Prefs 快捷路径取决于 iOS 系统行为，失败时按 App 提示手动进入系统设置。
